Programación Orientada a Objetos en C# 5.0

Guía Práctica: Modificadores de Acceso y Encapsulamiento

1. ¿Qué es el Encapsulamiento?

El encapsulamiento es uno de los cuatro pilares fundamentales de la Programación Orientada a Objetos (POO). Consiste en ocultar los detalles internos y el estado de un objeto, exponiendo únicamente una interfaz segura para interactuar con él.

¿Para qué sirve?

  • Protección de datos: Evita que el estado interno de un objeto sea modificado de forma indebida o inconsistente desde el exterior.
  • Mantenibilidad: Permite modificar la implementación interna de una clase sin afectar a otros componentes del programa que la utilicen.
  • Control de acceso: Permite definir propiedades de solo lectura, solo escritura o con validaciones personalizadas.

2. Modificadores de Acceso Principales

Los modificadores de acceso definen el nivel de visibilidad y alcance que tienen las clases, métodos y atributos dentro del proyecto:

  • public (Público): El miembro es accesible desde cualquier parte del código y desde otros ensamblados.
  • private (Privado): El miembro solo es accesible dentro de la misma clase donde fue declarado. Es la base del encapsulamiento.
  • protected (Protegido): El miembro es accesible dentro de su propia clase y por clases derivadas (herencia).

3. Ejemplo Práctico en C# v5.0

A continuación se presenta un ejemplo completo que demuestra el uso de atributos privados, propiedades auto-implementadas (característica presente en C# 5), métodos públicos y miembros protegidos mediante herencia: 

using System;

namespace EstructuraCSharp
{
    // Clase Base: CuentaBancaria
    public class CuentaBancaria
    {
        // ATRIBUTO PRIVADO: Encapsulado, no accesible fuera de esta clase
        private decimal saldo;

        // PROPIEDAD PÚBLICA: Permite acceso controlado al saldo (Lectura pública)
        public decimal Saldo
        {
            get { return saldo; }
            private set { saldo = value; }
        }

        // PROPIEDAD AUTO-IMPLEMENTADA (C# 5.0)
        public string Titular { get; set; }

        // CONSTRUCTOR PÚBLICO
        public CuentaBancaria(string titular, decimal saldoInicial)
        {
            Titular = titular;
            saldo = saldoInicial;
        }

        // MÉTODO PÚBLICO: Permite modificar el estado privado bajo reglas de negocio
        public void Depositar(decimal monto)
        {
            if (monto > 0)
            {
                saldo += monto;
                Console.WriteLine("Depósito exitoso. Nuevo saldo: {0:C}", saldo);
            }
        }

        // MÉTODO PROTEGIDO: Solo accesible por esta clase y sus clases hijas (herencia)
        protected void NotificarOperacion(string mensaje)
        {
            Console.WriteLine("[NOTIFICACIÓN]: {0}", mensaje);
        }
    }

    // Clase Derivada (Herencia)
    public class CuentaAhorro : CuentaBancaria
    {
        public decimal TasaInteres { get; set; }

        public CuentaAhorro(string titular, decimal saldoInicial, decimal tasa)
            : base(titular, saldoInicial)
        {
            TasaInteres = tasa;
        }

        public void AplicarInteres()
        {
            decimal interes = Saldo * TasaInteres;
            Depositar(interes);
            // Uso del método protegido de la clase padre
            NotificarOperacion("Se aplicó el interés mensual al saldo.");
        }
    }

    // Clase Principal (Punto de entrada)
    class Program
    {
        static void Main(string[] args)
        {
            CuentaAhorro miCuenta = new CuentaAhorro("Fabian Cáceres", 1000.00m, 0.05m);

            Console.WriteLine("Titular: {0}", miCuenta.Titular);
            miCuenta.Depositar(500);
            miCuenta.AplicarInteres();

            // miCuenta.saldo = 5000; // ERROR DE COMPILACIÓN: 'saldo' es privado
            // miCuenta.NotificarOperacion("Test"); // ERROR: 'NotificarOperacion' es protegido
        }
    }
}
